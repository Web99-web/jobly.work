# jobly.work
Regional job and classifieds network for Croatia.

## Nove podstranice

Na vrh nove HTML datoteke stavi dva retka s `---` (prazan Jekyll front matter), zatim dodaj cijeli HTML dokument s oznakom `</body>`. Ako kopiraš postojeću stranicu, zadrži prva dva retka. GitHub Pages pri objavi koristi zajednički predložak `_layouts/jobly.html` i automatski dodaje Cloudflare Web Analytics prije `</body>`.
